## LED Chaser

**File:** `Arduino_LED_Chaser_Circuit.ino`

### Project Overview
An Arduino UNO project using eight LEDs connected to digital
pins 2–9 through individual 110-ohm current-limiting resistors.

### Features
- Sequential LED illumination
- Forward and reverse LED patterns
- Array-based pin management
- 200 ms timing interval

### Hardware
- Arduino UNO
- 8 LEDs
- 8 × 110-ohm resistors
- Breadboard and jumper wires
