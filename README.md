### Autonomous Mobile Robot (AMR)

My autonomous mobile robot project combines embedded systems and ROS 2 to support sensor integration, robot description, mapping, and autonomous navigation.

Technologies and components include:

- Arduino
- ROS 2 Humble
- Python
- C++
- Ubuntu Linux
- Jetson Nano
- YDLIDAR X3 Pro
- Wheel encoders
- Ultrasonic sensors
- SLAM Toolbox
- Nav2

Individual implementation files and configurations will be added as they are organized and verified.
