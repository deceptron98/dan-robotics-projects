# Dan's Robotics & Embedded Systems Portfolio

Welcome to my robotics and embedded systems portfolio. This repository documents projects developed during my Industrial Training (IT), covering Arduino programming, sensor integration, robotic control, and autonomous mobile robotics.

### Robotics

- [Line-Following Robot](Robotics/Line_Following_Robot/) — Two-sensor line tracking with motor-speed control.
- [Obstacle-Avoiding Robot](Robotics/Obstacle_Avoiding_Robot/) — Reactive obstacle avoidance using IR and ultrasonic sensors.
- [Smart Toll Gate System](Robotics/Smart_Toll_Gate/) — Ultrasonic vehicle detection and servo-operated barrier control.

### Autonomous Mobile Robot (AMR)

My AMR project integrates embedded hardware with ROS 2 for mobile robot sensing, odometry, robot description, mapping, and autonomous navigation.

**Technology stack and hardware:**
- ROS 2 Humble
- Python and C++
- Ubuntu Linux
- NVIDIA Jetson Nano
- YDLIDAR X3 Pro
- Wheel encoders and ultrasonic sensors
- SLAM Toolbox and Nav2

The AMR implementation and supporting configurations are maintained separately from the smaller Arduino projects as they are organized and documented.
